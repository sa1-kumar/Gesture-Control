# Gesture-Controlled Volume App 🎚️

This project allows users to control system volume using hand gestures captured via a webcam. Built with Python, MediaPipe, and OpenCV, it uses real-time fingertip distance (between thumb and index finger) to adjust audio levels.

## Features
- Real-time gesture recognition using MediaPipe hand tracking
- Maps finger distance to system volume control
- <30ms response time for smooth user experience
